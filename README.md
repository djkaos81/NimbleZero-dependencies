# NimbleZero-dependencies

Libraries and runtimes for [NimbleZero](https://github.com/djkaos81/NimbleZero), the Linux
system for the M5Stack Cardputer Zero.

**Nothing is published here yet.** This repository is where installable packages will live
for software that apps need and the base system does not carry: language runtimes, media
libraries, fonts, the runtime for M5Stack app packages, and the like. The plan is that the
base image stays small and everything else is installed from here by the user's choice.

NimbleZero is unofficial firmware: not an M5Stack product, and not endorsed by M5Stack or
Raspberry Pi Ltd.
